Sicherung

Speichere deinen Fortschritt als Text oder Datei, zum Beispiel um ihn auf ein anderes Gerät zu übertragen. Beim Einlesen wird nichts überschrieben: Beide Stände werden zusammengeführt.

Mit GitHub synchronisieren

Dein Fortschritt wird als private Notiz (Gist) in deinem GitHub-Konto gespeichert und auf allen Geräten abgeglichen, auf denen du denselben Schlüssel einträgst. Der Schlüssel bleibt nur auf diesem Gerät.

So bekommst du einen Schlüssel
  1. Auf github.com oben rechts auf dein Profilbild, dann Settings.
  2. Ganz unten links Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Name z. B. „Lumo“, Ablaufdatum nach Wunsch. Unter Account permissions bei Gists „Read and write“ wählen. Sonst nichts.
  4. Generate token, den Schlüssel kopieren und hier einfügen.
